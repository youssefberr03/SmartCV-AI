
# SmartCV AI

## Intelligent Resume Analysis and Job Matching

SmartCV AI is a full-stack artificial intelligence
project focused on resume analysis and job matching.

The project combines Natural Language Processing,
Machine Learning and web development to help job
seekers understand how their resumes match job offers.

## Main Features

- PDF resume text extraction
- Natural Language Processing
- Skill extraction
- Job description analysis
- Resume-job similarity
- Semantic matching
- Personalized recommendations
- Resume analysis dashboard

## Technologies

### Artificial Intelligence

- Python

- spaCy
- PyTorch
- Sentence Transformers
- PyMuPDF

### Backend

- Java
- Spring Boot

- PostgreSQL

### Frontend

- React
- TypeScript

## Purpose

Personal project focused on Artificial Intelligence,
Natural Language Processing and Full Stack Development.

The application provides informational feedback to
job seekers rather than automated hiring decisions.
